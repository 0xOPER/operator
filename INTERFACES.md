# Public seams

There's no compatibility promise before 1.0. Semver starts there. Each seam says what would count as a break then.

| Seam | Version | What it is | A break would be |
|---|---|---|---|
| `bin/operator.sh` verbs | 0 | `status`, `doctor`, `rules`, `help`, `--version`, `--selftest`, `<tool>` passthrough (`--json` forwarded to `status`, `doctor`, `rules`) | Removing a verb, or changing what an exit code means |
| Tool verbs | 0 | What each tool's header lists across `bin/` and `scripts/` (`bin/operator.sh help` lists every entry point) | Removing a verb |
| Exit codes | 0 | 0 ok, 1 refused or missing, 2 usage or VOID, 3 a lock is held (advance/run lock busy, or call-log's lock busy), and `call-log.sh record` exits with the command's own code | Any change |
| `OPERATOR_HOME` | 0 | State root. Default `$XDG_STATE_HOME/operator`, else `~/.local/state/operator` | Changing the default without a migration |
| `OPERATOR_WORKSPACES` | 0 | Colon-separated program roots. Default `$OPERATOR_HOME/workspaces` | Changing the separator or default |
| `CALL_LOG_FILE` | 0 | Call log path. Default `$OPERATOR_HOME/call-log.tsv` | Changing the default without a migration |
| `OPERATOR_BIN_DIR`, `RUN_ALL_FLOOR`, `RUN_ALL_CEILING`, `LINE_TIMEOUT`, `WAVE_JOB_FIXTURE` | none | Test seams, with no promise | None |
| `call-log.tsv` | 2 | ts, id, label, keys, argv hash, stdout hash, stderr hash, rc, prev, row hash. Keys are `k=v` pairs from `record --key`, `-` when none, so check results file by row id, commit and arm ruling hash. Rows append under an exclusive flock | Changing a column's meaning, or a row shape, without a schema bump |
| `contract.py` verbs | 2 | validate, lint, doctor, run, advance, done, setup, amend, forge on a program dir's `contract.toml` (schema 2). advance, done and setup hold the program's lock (flock; busy is rc 3). `setup` runs `[setup]` inside an isolated jail bridged through `egress-proxy.py` (`setup.network` policy) and atomically populates `env/` (bound read-only at `/env` for rows). A row's `gpu = true` rides the check jail with the host's nvidia devices; a host with no GPU Voids naming its fix. A row's `env = "<name>"` runs its check through `environment.py` in a signed environment, with the jail's read-only overlays mounted at their paths; the row must name a declared environment and keep its timeout within the environment's wall | Removing or renaming a verb |
| `environment.py` verbs, `charter.toml` | 2 | validate, run over a program dir's `charter.toml` (schema 1; a program without one is the degenerate charter). `[[environment.<name>]]`: digest-pinned `image` (present locally, never pulled), `runtime` (docker), `devices`, `mounts` (`HOST:ro` or `HOST:rw`: never the host root, a system path, a container socket, or the engine's own tree and state), `network` (`none`), `rootfs` (`ro`), `writable` tmpfs, `user` (`uid:gid`, never root, the engine's own uid), `limits` (memory, cpus, pids, wall). The only container client; the arm ruling is verified before every run; every run files a hash-chained receipt `env:<name>` (env, image, argv hash, rc, secs, runtime). A seat with `env = ["<name>"]` (each declared in the charter) gets the door in its jail as `/op-envd.sock` (`OPERATOR_ENV_SOCKET`) with the client `bin/lib/op-env.py` at `/engine/op-env.py`; one request at a time, `budget.env_minutes` bounds it, and the door opens with the turn and closes with it | Pulling an image, launching without a verified ruling, a run with no receipt, or a door that outlives its turn |
| `ruling.py` verbs, `approvals` | 2 | closure, sign (alias `approvals approve`), verify, arm-hash, show, check, over a program dir's canonical closure (schema 1: sorted component hashes, base, core sha + dirty, signers sha). Signatures are ssh-keygen -Y in the operator-ruling namespace; a rotated-out signer fails verify. An arm ruling may carry `run` and `not_after`, which spawn's verify enforces when present | Removing a verb, a closure component, or ignoring the bindings |
| `team.py` verbs | 2 | validate over team.toml (schema 1) against the program's contract. Grants default to nothing; memory, skills and mcp carry inert this wave; enforceability refuses until adapter manifests name their tested range; waivable findings print as `needs-waiver <name>` (budget=advisory, rule-of-two, unreviewed-rows). Seat `gpu = true` puts the host's nvidia devices in that seat's jails (Void naming the fix on a host with none); seat `ro = ["/abs/data"]` mounts read-only host paths at their own paths -- absolute, distinct, existing, never on a jail-owned mount, never resolving into the engine's own tree or state; both are captured into the attempt's meta at build time | Removing a check, or a grant default |
| `compose-fence.py` | 2 | compose over marked text: a random per-compose delimiter checked absent from the text, lenient close-tag neutralisation, three format classes stripped and counted | Weakening the delimiter law or the classes |
| `audit-hook.py`, `OPERATOR_HOOK_LOG` | 2 | the tracked source of the CLI hook: one capped, control-stripped line per tool call into the run log a rendered instance names. Logging at 0.1; refusal is the conformance layer | Making it follow payload content, or write anywhere but the named log |
| `run.py` verbs | 2 | `start`, `tick`, `loop`, `operate`, `status`, `next`, `approvals`, `reply`, `retry`, `cancel`, `stop`, `resume`, `tail`, `sessions`, `report`, `gc` over `$OPERATOR_HOME/runs/<run>/`. The pager pages on every pause transition the machine observes -- a halt or an all-escalated pause (a file by default, `<run>/pages.tsv`, or `OPERATOR_PAGER_COMMAND` with the message on stdin -- a refusing or broken backend leaves the state unadvanced, logs a page-retry and the next tick re-sends); a STOP sentinel pauses directly, the operator's own hand needing no page. Three consecutive non-clean ticks notify once and turn status red until a clean tick re-arms it; a refused notify page leaves a page-retry row. Deterministic state machine: settle on parsed cost or in full on null, never release on a claim; STOP sentinel + namespace-scoped TERM; no-progress halt; `events.jsonl` schema 1. A namespace sweep never runs against the runner's own namespace | Removing a verb, or sweeping outside the recorded namespace |
| `spawn.py` verbs | 2 | init-run, attempt, compose, worker (stub path until adapter manifests), seal, gate, collect, candidate, promote, reject, verify, admit, reserve, over `$OPERATOR_HOME/runs/<run>/`. Engine git runs scrubbed on parent objects only; worker bytes cross only through a jail or the supervisor's pipes. Attempt caps are engine constants (64 MiB per attempt summed per changed path, 2000 paths), never team keys. A refused candidate keeps its attempt ref as evidence; gate, candidate, promote and reject hold the run's lock | Removing a verb, moving a byte cap into a team key, or deleting evidence on refusal |
| `runs/<run>/` layout | 2 | `parent/` (the run-owned repo, `integration/R`, `refs/attempts/*`, `refs/heads/candidate/*`), `attempts/<id>/{repo,out,home,seal,compiled}`, `ledger.tsv`, `run.json`, `STOP` sentinel | Renaming a path without a migration |
| `check.py` | 2 | the front door: git >= 2.38 (bundle-fsck note below 2.48), bubblewrap, openssh, python >= 3.11, venv/ensurepip named, writable OPERATOR_HOME, signers hygiene, adapter dir. Every missing piece names its fix; --json carries the same | Dropping a probe, or a refusal without its fix |
| `upstream.py` | 2 | the scripted provider on 127.0.0.1: three faces (/anthropic messages, /openai responses, /compat chat completions), request bodies logged verbatim with auth headers, scripted rows in order then defaults, 1 MiB body cap, 404 off-route | Following anything a request carries, or binding off loopback |
| `rules.py` | 2 | what each seat may do right now, from team.py's loaded state: grants, budgets, waivers (unreviewed-rows, rule-of-two, budget=advisory:<seat>) named on every screen; --json carries the same | Reading authority from anywhere but the ruled team |
| `init.py` | 2 | program scaffolding: --template feature (validates through team.py and contract.py), --key registers a public signer and REFUSES a plain key (passphrase named as the fix), --hook renders the two-line audit-hook instance (env names the log, execs the tracked source) | Accepting a plain key, or a template that doesn't validate |
| `review.py` verbs | 2 | `pack <attempt>`, `verdict <run> <task> --by <seat> --green\|--red\|--changes [--note FILE] [--key KEY] [--attempt DIR]`, `show <run> [task]`. Builds nonce-fenced diff packs (`PACK_CAP` 128 KiB), records human-signed or adapter-provenanced verdicts, and gates `spawn.py` promotion | Delivering a reviewed task without a current matching green verdict |
| `panel.py` verbs | 2 | `render [--run R] [--out F]`, `serve [--run R] [--port N]` (default `127.0.0.1:8765`, overridable via `OPERATOR_PANEL_BIND`). Loopback view backed by engine CLIs (`status`, `approvals`, `census`); `POST /verb` runs only whitelisted verbs (`stop`, `resume`, `cancel`, `reply`) | Computing state outside engine CLIs, or exposing non-whitelisted verbs |
| `memory.py` verbs | 2 | `init`, `add --seat <s> --scope self\|team --note FILE [--by <who>]`, `promote --id N --by <who>`, `snapshot [--seat S] [--last N]`, `show [--seat S] [--last N]`. Append-only sqlite note store (schema 1) rendered fenced into briefs | Letting a worker write directly to the note store |
| `wire.py` verbs | 2 | `send`, `receive`, `pump`, `show`. Asynchronous SSH-signed JSON envelopes (schema 1) delivered as fenced mail in the next brief | Accepting unsigned mail or delivering unfenced |
| `skills.py` verbs | 2 | `catalog <program-dir> [--seat S]`, `verify <program-dir> [--seat S]`. Lists and verifies SHA-256 hashes of program skills covered by the signed closure | Passing verification on drifted skill files |
| `tool-fence-hook.py` | 2 | `PostToolUse` hook planted on hooked CLIs (`claude-code`, `zcode`): drops tool payload and emits a capped `hookSpecificOutput.additionalContext` reminder that tool output is untrusted data | Echoing raw payload bytes into persona context |
| `demo.py` (`bin/operator.sh demo`) | 2 | offline 60-second demo: runs stub seats, sealed contract checks, an outside-write refusal, and a local-listener network fence check; cleans up unless `--keep DIR` is passed; exits non-zero (`sandbox=unavailable`) if `bubblewrap` is missing | A green row without the work, or a listener hit for a denied host |
| `egress-proxy.py` verbs | 2 | serve (a Unix socket bound by basename after chdir, one request per connection: CONNECT on 443 with the ClientHello naming the host, plain HTTP setup-only on 80, the boundary re-read per connection, proxy-side resolution, every address global by ipaddress and none held locally, deny rules beating allow, ` until <UTC>` expiring a rule, `pin <host> <addr> <port>` as the operator's vouch -- no DNS, the log says pinned, every other law applies -- one log row per connection with control characters stripped, a full log or an unwritable log refusing everything) and relay (the in-jail leg: TCP on the lonely loopback pumped to the one socket) | Letting a private, local or expired target through, writing a second row for one CONNECT, or echoing a refused credential's bytes |
| `broker.py serve` | 2 | the engine's wire to the provider: unix socket, exact routes (/v1/messages, /v1/responses), the client's authorization stripped and the engine credential injected, one usage row per turn. `--turn-input-cap <tokens>` sets the per-turn input ceiling (fresh + cache-read + cache-created): an early-usage wire is CUT mid-stream at the ceiling (hard abort, the triggering chunk never reaches the client, the row records `capped`); a late-reporting wire finishes but records the breach, and the seat's context budget gates the next reservation | Relaying past the ceiling, or a clip that lies about what the model sent |
| `fixtures.py` verbs | 2 | run [--keep DIR]: one repeatable walk through the engine -- two stub seats, a contract stricter than the template (exact content, a reviewer per row), the stub adapter driven by an engine-written plan (cost and session parsed from its stream), attempt through promote, the contract's rows on the promoted parent, one scripted call to the loopback upstream with the body read back verbatim from the request log. The report is one line of numbers (checks, rows, time, cost) and any number that misses what the plan said is a refusal, never a printed lie. Synthetic tasks only | Reporting a number the walk didn't produce, or green rows without the walk |
| `census.py` verbs, `OPERATOR_CENSUS_LOG` | 2 | install (PATH-first shims per agent CLI including `zcode` plus the ssh-keygen proxy that passes everything but `-Y sign` through; a dir it owns; `--real NAME=PATH` stubs a backstop) and report (rows/admit/refuse; any refuse or unreadable row exits 1; an absent log is zero rows). A censused call logs its /proc caller chain and admits only through its door -- spawn.py for agent CLIs, ruling.py/approvals/review.py/wire.py for signing -- and a missing or unwritable log refuses | Admitting a call with no door in its chain, or passing a `-Y sign` uncensused |
| `lint-spawn.py`, `AGENT_CLIS` | 2 | the static hint over sh, py and shebang executables: command-position agent-CLI spawns in the twenty shapes the spawn-gate audit proved (quoted, spliced, variable-held, base64-decoded, wrapper paths, door verbs, path forms, python call sites); mentions, comments and argument positions stay clean; `# census: allow` is counted, never silent | Losing a shape from the twenty, or flagging the audit's false positives |
| Adapter manifests, `spawn.py adapter`, `spawn.py preflight` | 2 | `config/adapters/<name>.toml` (`OPERATOR_ADAPTERS` overrides, schema 2): `tested_classes` (`network` and `shell` only where their conformance cells are green), `tool_fencing` (`hooked` \| `unfenced`), `report_mount`, `argv` with `{PLAN}`/`{BRIEF}`/`{BROKER}`/`{MODEL}`, `engine_bins` bound ro under `/engine`, `credential_env` (refuses keyless and live-shaped API secrets), `broker_env`, `broker_sock_env` (per-provider broker socket env), `must_create`, `repo_config`, `nproc_headroom`, `retry_class`, session/cost fields. `preflight <adapter>` probes the binary and semver floor (`--strict` requires exact equality) | A manifest demanding a live key, a below-floor version recorded as ok, or silently riding the wrong provider |
| Broker & turn-cap env vars | 2 | `OPERATOR_CREDENTIAL` carries the non-secret placeholder inside `/w/compiled/adapter.env` (live-shaped secrets are refused). Host-side provider envs (`OPERATOR_BROKER_ORIGIN`/`OPERATOR_BROKER_CREDENTIAL`, `OPERATOR_ANTHROPIC_*`, `OPERATOR_OPENAI_*`, `OPERATOR_ZAI_*`) cause `run.py` to auto-supervise `broker.py serve` on `/tmp/opb-*/b.sock` with a per-run `OPERATOR_BROKER_SEAT_KEY` (HMAC seat-token attribution) and per-attempt ceilings `OPERATOR_TURN_INPUT_CAP` (default `500000`) and `OPERATOR_TURN_USD_CAP` (default `10.00`). Manual `broker.py serve` requires `OPERATOR_BROKER_SEAT_KEY` for per-attempt attribution and caps | Passing a live upstream API key inside the jail, or dropping per-attempt attribution |
| `OPERATOR_DISK_FLOOR` | none | Test seam: the free-space floor the supervisor's statvfs watcher enforces, bytes | None |
| `reach.py` verbs, the egress policy | 2 | policy and check over a program dir's `charter.toml` and a seat's `network` grant: the profile (`closed`, `dev`, `research`) names categories, `[reach].allow` widens, `[reach].deny` beats every allow, `[reach].pins` vouches `host=IPv4:port`; a grant outside the charter refuses at `team validate` and again where the jail is built; `*` is the charter's reach and never more. A seat with a grant gets the egress proxy in its adapter jail: host-side for the turn, its socket bound at `/egress.sock`, an in-jail relay on 3129, the standard proxy variables set with the broker excluded, one log row per connection under `<attempt>/egress/`. `egress-proxy.py` refuses a credential shape in a request head it can read (the CONNECT line and headers, a plain-HTTP request) before resolving or connecting, and its reason never carries the bytes | A policy the charter didn't sign, a grant beyond the charter, a proxy that outlives its turn, or a connection with no log row |
| `derive.py` verbs | 2 | rows over a work repo at a commit (pytest, unittest, Makefile targets, package.json scripts, cargo, go: each a sealed row whose oracle pins what the runner reads) and pin over a program dir and an engine-initialized run parent (every derived row once at the commit, through the check jail; red ones are the known-red baseline; nothing is filed) | A derived row with nothing pinned, a pin that hides a red row, or a pin that files a result |
| `OPERATOR_CONTAINER_CLI` | none | Test seam: the container runtime's command. It must name a fixture under `test/`; anything else refuses | None |
| `OPERATOR_SIGNERS` | 2 | Signers file, default `$OPERATOR_HOME/signers/allowed_signers`, outside every bind. Entries must restrict `namespaces=` to operator-ruling | Moving it under a bind |
| `CONTRACT_REPO`, `CONTRACT_TIP`, `CONTRACT_PIN`, `CONTRACT_ARM` | 2 | The work repo the export comes from, the commit under evaluation (default HEAD), the oracle pin (default the tip; the ruled base once rulings exist) and the arm ruling hash (default `-`). Check results file in `call-log.tsv` keyed row, commit, arm, rc | Changing a meaning |
| Fence spans | 0 | `<span-untrusted source="...">`, rewritten by `wrap` to `<untrusted source="...">` | Changing either tag or the notice line |
