# Public seams

There's no compatibility promise before 1.0. Semver starts there. Each seam says what would count as a break then.

| Seam | Version | What it is | A break would be |
|---|---|---|---|
| `bin/operator.sh` verbs | 0 | `status`, `doctor`, `rules`, `help`, `--version`, `--selftest`, `<tool>` passthrough (`--json` forwarded to `status`, `doctor`, `rules`) | Removing a verb, or changing what an exit code means |
| Tool verbs | 0 | What each tool's header lists: `call-log.sh`, `contract.py`, `run.py`, `spawn.py`, `untrusted-span-fence.py`, `release-lint.py` | Removing a verb |
| Exit codes | 0 | 0 ok, 1 refused or missing, 2 usage or VOID, 3 advance/run lock busy, or call-log's lock busy. `test/wave-job.sh` uses 3 for receipts owed, and `call-log.sh record` exits with the command's own code | Any change |
| `OPERATOR_HOME` | 0 | State root. Default `$XDG_STATE_HOME/operator`, else `~/.local/state/operator` | Changing the default without a migration |
| `OPERATOR_WORKSPACES` | 0 | Colon-separated program roots. Default `$OPERATOR_HOME/workspaces` | Changing the separator or default |
| `CALL_LOG_FILE` | 0 | Call log path. Default `$OPERATOR_HOME/call-log.tsv` | Changing the default without a migration |
| `OPERATOR_BIN_DIR`, `RUN_ALL_FLOOR`, `RUN_ALL_CEILING`, `LINE_TIMEOUT`, `WAVE_JOB_FIXTURE` | none | Test seams, with no promise | None |
| `call-log.tsv` | 2 | ts, id, label, keys, argv hash, stdout hash, stderr hash, rc, prev, row hash. Keys are `k=v` pairs from `record --key`, `-` when none, so check results file by row id, commit and arm ruling hash. Rows append under an exclusive flock | Changing a column's meaning, or a row shape, without a schema bump |
| `contract.py` verbs | 2 | validate, lint, doctor, run, advance, done, setup, amend, forge on a program dir's `contract.toml` (schema 2). advance, done and setup hold the program's lock (flock; busy is rc 3). `setup` runs `[setup]` inside an isolated jail bridged through `egress-proxy.py` (`setup.network` policy) and atomically populates `env/` (bound read-only at `/env` for rows). A row's `gpu = true` rides the check jail with the host's nvidia devices; a host with no GPU Voids naming its fix | Removing or renaming a verb |
| `ruling.py` verbs, `approvals` | 2 | closure, sign (alias `approvals approve`), verify, arm-hash, show, check, over a program dir's canonical closure (schema 1: sorted component hashes, base, core sha + dirty, signers sha). Signatures are ssh-keygen -Y in the operator-ruling namespace; a rotated-out signer fails verify. An arm ruling may carry `run` and `not_after`, which spawn's verify enforces when present | Removing a verb, a closure component, or ignoring the bindings |
| `team.py` verbs | 2 | validate over team.toml (schema 1) against the program's contract. Grants default to nothing; memory, skills and mcp carry inert this wave; enforceability refuses until adapter manifests name their tested range; waivable findings print as `needs-waiver <name>` (budget=advisory, rule-of-two, unreviewed-rows). Seat `gpu = true` puts the host's nvidia devices in that seat's jails (Void naming the fix on a host with none); seat `ro = ["/abs/data"]` mounts read-only host paths at their own paths -- absolute, distinct, existing, never on a jail-owned mount, never resolving into the engine's own tree or state; both are captured into the attempt's meta at build time | Removing a check, or a grant default |
| `compose-fence.py` | 2 | compose over marked text: a random per-compose delimiter checked absent from the text, lenient close-tag neutralisation, three format classes stripped and counted | Weakening the delimiter law or the classes |
| `audit-hook.py`, `OPERATOR_HOOK_LOG` | 2 | the tracked source of the CLI hook: one capped, control-stripped line per tool call into the run log a rendered instance names. Logging at 0.1; refusal is the conformance layer | Making it follow payload content, or write anywhere but the named log |
| `run.py` verbs | 2 | start, tick, status, next, stop, resume, tail, report over `$OPERATOR_HOME/runs/<run>/`. The pager pages on every pause transition the machine observes -- a halt or an all-escalated pause (a file by default, one row per page, or OPERATOR_PAGER_COMMAND with the message on stdin -- a refusing or broken backend leaves the state unadvanced, logs a page-retry and the next tick re-sends); a STOP sentinel pauses directly, the operator's own hand needing no page. Three consecutive non-clean ticks notify once and turn status red until a clean tick re-arms it; a refused notify page leaves a page-retry row. Deterministic state machine (decision 28): settle on parsed cost or in full on null, never release on a claim; STOP sentinel + namespace-scoped TERM; no-progress halt; events.jsonl schema 1 with domain/generation/batch reserved. A namespace sweep never runs against the runner's own namespace | Removing a verb, or sweeping outside the recorded namespace |
| `spawn.py` verbs | 2 | init-run, attempt, compose, worker (stub path until adapter manifests), seal, gate, collect, candidate, promote, reject, verify, admit, reserve, over `$OPERATOR_HOME/runs/<run>/`. Engine git runs scrubbed on parent objects only; worker bytes cross only through a jail or the supervisor's pipes. Attempt caps are engine constants (64 MiB per attempt summed per changed path, 2000 paths), never team keys. A refused candidate keeps its attempt ref as evidence; gate, candidate, promote and reject hold the run's lock | Removing a verb, moving a byte cap into a team key, or deleting evidence on refusal |
| `runs/<run>/` layout | 2 | `parent/` (the run-owned repo, `integration/R`, `refs/attempts/*`, `refs/heads/candidate/*`), `attempts/<id>/{repo,out,home,seal,compiled}`, `ledger.tsv`, `run.json`, `STOP` sentinel | Renaming a path without a migration |
| `check.py` | 2 | the front door: git >= 2.38 (bundle-fsck note below 2.48), bubblewrap, openssh, python >= 3.11, venv/ensurepip named, writable OPERATOR_HOME, signers hygiene, adapter dir. Every missing piece names its fix; --json carries the same | Dropping a probe, or a refusal without its fix |
| `upstream.py` | 2 | the scripted provider on 127.0.0.1: three faces (/anthropic messages, /openai responses, /compat chat completions), request bodies logged verbatim with auth headers, scripted rows in order then defaults, 1 MiB body cap, 404 off-route | Following anything a request carries, or binding off loopback |
| `rules.py` | 2 | what each seat may do right now, from team.py's loaded state: grants, budgets, waivers (unreviewed-rows, rule-of-two, budget=advisory:<seat>) named on every screen; --json carries the same | Reading authority from anywhere but the ruled team |
| `init.py` | 2 | program scaffolding: --template feature (validates through team.py and contract.py), --key registers a public signer and REFUSES a plain key (passphrase named as the fix), --hook renders the two-line audit-hook instance (env names the log, execs the tracked source) | Accepting a plain key, or a template that doesn't validate |
| Adapter manifests, `spawn.py adapter` | 2 | config/adapters/<name>.toml (OPERATOR_ADAPTERS overrides): tested_classes (team.py), argv with {PLAN}/{BRIEF}, engine_bins bound ro under /engine. The stub ships first: a plan the ENGINE wrote (compiled/plan.json) drives it, never brief text. `broker_sock_env = "OPERATOR_BROKER_SMART"` names the env var holding that adapter's OWN broker socket (one socket per provider: the smart reviewer rides one origin while the workers ride another; default OPERATOR_BROKER) | Letting a worker take instructions from the brief, or an adapter silently riding the default provider |
| `demo.py` (`operator demo`) | 2 | the whole engine on one screen, first level: two stub seats to green rows through worker, seal, gate and promotion in under 60 seconds; a forged claim leaves every row red until honest evidence exists; the outside write refused and reported while the same write inside the layout lands; the network fence end to end (a listener behind the egress proxy: nothing for a denied host, one hit for an allowed host through the jail's relay, one more for the same connect from the host); `sandbox=unavailable`, its meaning and a non-zero exit when bubblewrap is missing | A green row without the work, or a listener hit for a denied host |
| `egress-proxy.py` verbs | 2 | serve (a Unix socket bound by basename after chdir, one request per connection: CONNECT on 443 with the ClientHello naming the host, plain HTTP setup-only on 80, the boundary re-read per connection, proxy-side resolution, every address global by ipaddress and none held locally, deny rules beating allow, ` until <UTC>` expiring a rule, `pin <host> <addr> <port>` as the operator's vouch -- no DNS, the log says pinned, every other law applies -- one log row per connection with control characters stripped, a full log or an unwritable log refusing everything) and relay (the in-jail leg: TCP on the lonely loopback pumped to the one socket) | Letting a private, local or expired target through, or writing a second row for one CONNECT |
| `broker.py serve` | 2 | the engine's wire to the provider: unix socket, exact routes (/v1/messages, /v1/responses), the client's authorization stripped and the engine credential injected, one usage row per turn. `--turn-input-cap <tokens>` sets the per-turn input ceiling (fresh + cache-read + cache-created): an early-usage wire is CUT mid-stream at the ceiling (hard abort, the triggering chunk never reaches the client, the row records `capped`); a late-reporting wire finishes but records the breach, and the seat's context budget gates the next reservation | Relaying past the ceiling, or a clip that lies about what the model sent |
| `fixtures.py` verbs | 2 | run [--keep DIR]: one repeatable walk through the engine -- two stub seats, a contract stricter than the template (exact content, a reviewer per row), the stub adapter driven by an engine-written plan (cost and session parsed from its stream), attempt through promote, the contract's rows on the promoted parent, one scripted call to the loopback upstream with the body read back verbatim from the request log. The report is one line of numbers (checks, rows, time, cost) and any number that misses what the plan said is a refusal, never a printed lie. Synthetic tasks only | Reporting a number the walk didn't produce, or green rows without the walk |
| `census.py` verbs, `OPERATOR_CENSUS_LOG` | 2 | install (PATH-first shims per agent CLI including `zcode` plus the ssh-keygen proxy that passes everything but `-Y sign` through; a dir it owns; `--real NAME=PATH` stubs a backstop) and report (rows/admit/refuse; any refuse or unreadable row exits 1; an absent log is zero rows). A censused call logs its /proc caller chain and admits only through its door -- spawn.py for agent CLIs, ruling.py/approvals/review.py/wire.py for signing -- and a missing or unwritable log refuses | Admitting a call with no door in its chain, or passing a `-Y sign` uncensused |
| `lint-spawn.py`, `AGENT_CLIS` | 2 | the static hint over sh, py and shebang executables: command-position agent-CLI spawns in the twenty shapes the spawn-gate audit proved (quoted, spliced, variable-held, base64-decoded, wrapper paths, door verbs, path forms, python call sites); mentions, comments and argument positions stay clean; `# census: allow` is counted, never silent | Losing a shape from the twenty, or flagging the audit's false positives |
| Adapter manifests, `spawn.py adapter`, `spawn.py preflight` | 2 | config/adapters/<name>.toml (OPERATOR_ADAPTERS overrides): schema 2 carries P's values — argv with {PLAN}/{BRIEF}/{BROKER}/{MODEL}, credential_env (refuses keyless and refuses live-shaped API secrets: the placeholder value comes from OPERATOR_CREDENTIAL, never the program), broker_env, must_create dirs (CODEX_HOME before launch), repo_config the engine plants with the broker baked in, nproc_headroom, retry_class, session/cost fields. `preflight <adapter>` probes the binary and its semver floor (`--strict` requires exact equality) | A manifest demanding a credential that isn't a broker placeholder, or a below-floor version recorded as ok |
| `OPERATOR_CREDENTIAL`, `OPERATOR_BROKER_ORIGIN`, `OPERATOR_BROKER_CREDENTIAL` | 2 | `OPERATOR_CREDENTIAL` carries the non-secret placeholder token inside `/w/compiled/adapter.env` (live-shaped secrets are refused at `adapter_env`). When `OPERATOR_BROKER_ORIGIN` + `OPERATOR_BROKER_CREDENTIAL` are set on the host, `run.py` auto-supervises `broker.py serve` on `<run>/broker.sock`, keeps the real API key strictly host-side, and injects `broker-placeholder` automatically | Passing a live upstream API key into `OPERATOR_CREDENTIAL` inside the jail |
| `OPERATOR_DISK_FLOOR` | none | Test seam: the free-space floor the supervisor's statvfs watcher enforces, bytes | None |
| `OPERATOR_SIGNERS` | 2 | Signers file, default `$OPERATOR_HOME/signers/allowed_signers`, outside every bind. Entries must restrict `namespaces=` to operator-ruling | Moving it under a bind |
| `CONTRACT_REPO`, `CONTRACT_TIP`, `CONTRACT_PIN`, `CONTRACT_ARM` | 2 | The work repo the export comes from, the commit under evaluation (default HEAD), the oracle pin (default the tip; the ruled base once rulings exist) and the arm ruling hash (default `-`). Check results file in `call-log.tsv` keyed row, commit, arm, rc | Changing a meaning |
| Fence spans | 0 | `<span-untrusted source="...">`, rewritten by `wrap` to `<untrusted source="...">` | Changing either tag or the notice line |
| Lint rule file | 0 | TAB-separated `name regex reversed-sample` | Changing columns |
